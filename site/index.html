THE USEFUL DETAILS

Good questions.
Straight answers.

Ask on GitHub
Does this run on GitHub Pages?+

This project website does. The router itself runs on your own computer or server using Node.js or Docker. GitHub Pages serves static files and cannot run the router’s APIs.

Do I bring my own API keys?+

Yes. Add your documented provider API keys, or connect an auth-less local endpoint. Your clients use a Giga Router access key. Provider presets help with setup; they don’t grant credits or guarantee free access.

What happens when a provider fails?+

In auto mode, eligible startup failures can try the next provider in your chain. After output begins, an error is reported instead of mixing responses from different models. The dashboard explains attempts and cooldowns.

Will every API feature work with every model?+

Native routes retain provider-specific features. Translation between Chat Completions and Messages supports a documented subset. Responses forwarding requires a provider with that capability enabled. See the compatibility guide for the details.

Can I use it with a team?+

Giga Router is designed as a single-user workspace. Scoped access keys let your own clients use different APIs and MCP servers. It isn’t a multi-tenant account or billing platform.
