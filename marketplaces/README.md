# Bundled marketplace catalogs

`builtin/*.json.gz` contains real, pinned GitHub source indexes generated by
`npm run update:marketplaces`. The startup seed copies them into the instance's
data volume, so browse, preview, and Copy for chat work immediately, including
without a GitHub connection. Skill installation still downloads the selected
bundle from its indexed commit.

Each snapshot preserves its repository license text and source/commit metadata.
`builtin/manifest.json` records the packaged commits and catalog counts. See
`lib/marketplace-defaults.js` for the curated repository list and directory scope.

Catalogs are removable in Marketplace → My repositories. Deletion records a
persistent opt-out; startup/upgrades do not recreate removed sources. Existing
sources and user-refreshed indexes are preserved. Restore removed defaults is
an explicit dashboard action.

Set `GIGA_ROUTER_DEFAULT_MARKETPLACES=false` to disable automatic default seeding.
Refreshes of bundled release snapshots are explicit:

```sh
GITHUB_TOKEN=... npm run update:marketplaces
```

The updater requires all selected sources to have complete, MIT-licensed indexes
and a repository license file. It does not execute repository code.
